# Glossary

- **SPSC ring** — single-producer/single-consumer bounded queue; the only inter-core channel.
- **Cursor caching** — each ring side keeps a stale copy of the other side's index, refreshing only when it looks full/empty (or short of a batch).
- **False sharing** — two cores writing different variables on one cache line, bouncing it; prevented with `CachePadded` / 64 B messages.
- **Hot path** — feed → strategy → risk → broker; no allocation, locks or syscalls allowed.
- **Cold path** — everything else (config, reporting, world-data ingest, training).
- **PIT (point-in-time)** — a value computed only from data available strictly before the moment it's used; no look-ahead.
- **Surprise z-score** — `(x − prior_mean) / prior_std`, using estimator state *before* `x`.
- **Decayed surprise** — accumulated z with exponential time decay (half-life in ns).
- **View** — a strategy's `(mu, sigma2)` for an instrument; never a size.
- **Fractional Kelly** — size `f = k · mu/sigma2` of equity, with `k < 1` (default 0.25).
- **In-flight / pending qty** — quantity sent to a broker but not yet filled or cancelled.
- **Halt (daily DD latch)** — after the daily drawdown limit is hit, only flattening is allowed until `roll_day()`.
- **Stop-out** — position closed by the per-position stop-loss; triggers a cooldown.
- **Normalised equity** — equity rescaled to a $100.00 starting base for shareable reporting (FR-6).
- **Px / Qty** — fixed-point i64 at 1e-8 scale.
- **IOC** — immediate-or-cancel; unfilled remainder is reported as `Exec::Cancelled`.
- **Sans-IO** — protocol code (TLS, WebSocket) written as pure state machines over byte buffers; the I/O driver is separate and swappable.
- **Unbuffered rustls** — rustls API that decrypts TLS records in place in the caller's buffer, with no internal queues.
- **SQPOLL** — io_uring mode where a kernel thread polls the submission queue, so submitting needs no syscall.
- **CQ / SQ** — io_uring completion / submission queues (shared memory between user and kernel).
- **bookTicker** — Binance best bid/ask (top-of-book) stream; `u` is the book update id.
- **Stale update** — an event whose `seq` is ≤ the last seen for its instrument; dropped by the live runner.
- **wire→event** — latency from the socket read that delivered the bytes to the decoded event entering the ring.
- **SMT sibling** — two logical CPUs sharing one physical core (hyper-threading); never pin two spinning stages to siblings.
- **Venue** — a market-data/execution provider adapter (`dd_feed::venues::Venue`).
- **`.env`** — git-ignored file of secret environment variables; `.env.example` lists the names.
- **cTrader Open API** — Spotware's free API for cTrader broker accounts (demo or live): quotes, history, trading.
- **CFD** — contract for difference; a broker-quoted instrument tracking an underlying (share, index, crypto).
- **ProtoMessage** — cTrader's envelope: `payloadType` (1), `payload` bytes (2), `clientMsgId` (3).
- **Spot event** — cTrader quote update; carries only the changed side(s), prices in 1/100000 units.
- **Playground** — cTrader Open API page that issues access tokens for your own accounts without building an OAuth flow.
- **Walk-forward** — repeatedly optimise on a past window (train) and evaluate the chosen parameters on the next unseen window (test); only stitched test results count.
- **OOS** — out-of-sample: data not used to choose parameters.
- **PSR** — probabilistic Sharpe ratio: probability the true Sharpe exceeds a benchmark, given sample length, skew and kurtosis.
- **DSR** — deflated Sharpe ratio: PSR against the best Sharpe expected from N skill-less trials; corrects for parameter search.
- **Win rate** — share of closing trades with positive P&L **net of costs** (owner gate: > 70%).
- **Profit factor** — gross winning P&L / gross losing P&L (gate ≥ 1.3).
- **Rollover** — 17:00 New York FX day boundary; financing is charged here (×3 on Wednesday).
- **Financing / swap** — overnight cost (or credit) on open CFD/FX positions.
- **.bi5** — Dukascopy's LZMA-compressed hourly tick file.
